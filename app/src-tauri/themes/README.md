# Built-in themes

Ghostty theme files bundled into the app.

- `Supacode Dark` (the default) and `Supacode Light`: Supacode's own palettes.
- `upstream/`: a curated set from [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
  `ghostty/` at commit b13ba4b1b2f7f14ab6e430ab5f9bccad742d3adb, MIT licensed (see `upstream/LICENSE`).

More themes are picked up at runtime from `~/.config/ftm/themes/` and from Ghostty or Supacode installs.
